# Local demo

Follow [local preview setup](preview-data.md) to start a dedicated database, API and frontend from the repository root. The guide includes prerequisites, sample accounts and reset instructions. The demo uses fictional businesses and orders, and you can explore it without Twilio or Stripe credentials.

1. Browse stringers and open a profile.
2. Try the guided setup or choose your own strings, then request a quote.
3. Use a customer preview session to place an order and open its tracking page.
4. Switch to a stringer owner session to accept the booking, update its status and inspect stock.
5. Use the administrator session to review the catalogue and business applications.

For an empty database and regular development setup, see the [engineering guides](../engineering/README.md).
